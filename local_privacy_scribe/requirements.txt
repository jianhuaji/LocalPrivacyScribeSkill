# ========== 安装说明 ==========
# 
# 基础安装（仅 CPU）：
#   pip install -r requirements.txt
#
# NPU 加速（Intel 神经网络处理器）：
#   1. 安装 OpenVINO NPU 驱动
#   2. pip install openvino[dev]
#   3. 在代码中设置 device="NPU"
#
# GPU 加速（Intel 集成显卡或 NVIDIA 独立显卡）：
#   Intel GPU: pip install openvino[dev]
#   NVIDIA GPU: 需要额外安装 OpenVINO CUDA 插件
#
# 验证安装：
#   python -c "from openvino.runtime import Core; print(Core().available_devices)"
#
# ========== 系统要求 ==========
# 
# 操作系统：Windows 10+, Linux (Ubuntu 20.04+), macOS 11+
# Python：3.8, 3.9, 3.10, 3.11
# 内存：建议 16GB 以上（用于加载 ASR/OCR 模型）
# 磁盘：至少 5GB 可用空间（模型文件 + 依赖包）
#
# ========== 注意事项 ==========
# 
# 1. 所有依赖均支持本地离线安装，无需云端 API
# 2. OpenVINO 模型文件需要单独下载并转换为 IR 格式
# 3. 首次运行时会自动下载模型到 ~/.cache/modelscope/LocalPrivacyScribe/
# 4. 建议使用虚拟环境（venv/conda）隔离依赖
# 5. 生产环境建议固定版本号以确保可重复构建
